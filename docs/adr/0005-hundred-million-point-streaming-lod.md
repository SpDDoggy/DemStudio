# ADR 0005：一亿源高程点流式 LOD

- 状态：已确认，实施中
- 日期：2026-07-29
- 决策者：用户

## 背景

DEM Studio 已能用 file-backed GeoTIFF 打开超大栅格，并以 128×128 overview
和单个 257×257 focus 窗口维持较低的常驻 GPU 几何量。但历史 20k 样本的
focus 延迟约 2.98 秒；既有 73.5 FPS 只证明旧的低精度网格可以继续旋转，
不能证明新视区细节能随相机流畅到达。

目标不是同时向 GPU 提交一亿顶点，而是流畅浏览
10,000×10,000＝100,000,000 个源高程样点。源数据规模不得决定同屏顶点、
GPU 资源或每帧工作量。

## 决定

采用文件型多级瓦片、视锥与屏幕空间误差驱动的流式 LOD：

1. Core 数据集以 `Arc` 快照离开全局注册表锁，重 I/O 在 blocking worker
   中执行。
2. 所有窗口/瓦片请求具有稳定 request id、优先级和真实取消；迟到结果既
   不得上屏，也应尽快停止解码。
3. GeoTIFF 解码块跨请求复用，并由字节硬上限约束；不得使用无界缓存或仅
   按条目数限制。
4. 前端用视锥与 SSE 选择多个稳定瓦片；交互和静止使用不同误差阈值、上传
   预算和活动瓦片预算。
5. 父瓦片持续显示到子瓦片全部 ready；父子替换必须有 2:1 邻接约束、边缘
   morph 或 skirts，不再通过反复重写整张 root 索引缓冲实现最终 LOD。
6. GPU 目标形态是共享规则网格加高程/有效性/遮蔽纹理。过渡阶段允许复用
   现有 CPU 网格，但不得把它称为最终完成。
7. DMT3 v2、最近文件、设置 schema 和旧采样命令保持兼容。新字段为可选，
   旧 root+focus 路径保留为回滚开关。
8. 原 DEM 永远只读。金字塔和块缓存是带源文件指纹与版本头的派生资产，
   损坏时丢弃重建。

## 放弃的替代方案

### 继续放大单 focus 窗口

会放大解码、主线程构网、光照 worker、IPC 和显存峰值，且不能覆盖完整视锥，
不满足规模不变性。

### 同屏绘制一亿顶点

仅顶点属性和索引就需要数 GB 内存，超过当前 WebGL 产品边界，并且在常见
显示分辨率下没有视觉收益。

### 只在交互时关闭后处理

只能改善旧网格旋转帧率，不能解决细节延迟、陈旧请求、重复解码和跨区浏览，
因此不能作为一亿点完成方案。

## 兼容与回滚

- DMT3 二进制格式保持不变。
- 原有 `sample_dem_*` 命令继续存在；新请求字段使用默认值兼容旧调用。
- 新调度器通过功能开关关闭后回到既有 root+focus。
- 派生缓存可直接删除，不影响源 DEM。
- 每个阶段必须通过旧 ASC/HGT/GeoTIFF、NoData、最近图片和白模渲染回归。

## 验收

正式结论必须使用 Release EXE 和确定性的 10,000×10,000 tiled Float32
GeoTIFF，保存二进制/fixture 哈希、硬件、GPU、逐请求及逐帧原始证据。

- 首个可信地形帧 p95 ≤ 2 秒。
- 冷瓦片精化 p95 ≤ 150 ms；缓存命中 p95 ≤ 50 ms。
- 60 秒真实 orbit、pan、zoom：帧间隔 p95 ≤ 16.7 ms，p99 ≤ 25 ms。
- 相机停止 250 ms 后无旧视域高优先级请求；过期 GPU 上传为 0。
- 取消响应 ≤ 50 ms。
- 完整进程树峰值工作集 ≤ 1.5 GiB。
- 15 分钟、至少 200 次视口变化后无单调内存增长、崩溃、WebGL context
  loss、洞、错层或可见接缝。
- 相同视角下，2500 万与一亿源点的帧耗时和 GPU 资源差异均 ≤ 10%。

任何一项缺失或只能由普通 RAF、文件名、UI 尺寸文字间接推断时，总体不得
判定为完成。

## 2026-07-30：外部金字塔与父子覆盖修正

真实 31,984 × 18,495 GeoTIFF 证明，最多 6 × 6 的统计块中心不能同时承担
显示根概览。该文件的连续金字塔和精确统计分别位于精确同名 `.tif.ovr`
与 `.tif.aux.xml`；忽略侧车会把不规则有效区膨胀为矩形，并用错误 min/max
压平高低端。

补充决定：

1. 统计抽样与显示概览分离。6 × 6 仅可作为有界统计回退，不得作为存在
   OVR/内嵌金字塔时的显示根层。
2. 路径型 GeoTIFF 可自动只读精确同名 `${path}.ovr` 与
   `${path}.aux.xml`；禁止目录模糊扫描。AUX XML 必须有大小上限，显式
   companion 优先。
3. 显示概览优先选择长宽比一致、分辨率接近目标且有界的金字塔 IFD。
4. PAM/GDAL min/max 只有在 finite 且 `min < max` 时可覆盖抽样统计。
5. Streaming tile 不得再向整幅 root overview 做宽 edge morph。同级采样
   保持源端点，跨级无缝后续必须使用真实父层，而不是 6 × 6 root。
6. 目标 display set 覆盖完整后撤下 root 顶面；基座厚度为 0 时同时撤下
   粗根边界墙，正厚度时保留基座和有效区边界墙；未覆盖完整时 root 继续
   作为 fallback。
7. Harness 必须校验 overview mask 指纹、父子覆盖完成、root 顶面可见性、
   请求队列归零和 morph 宽度，不能只校验活动网格数量。

本修正不改变 DMT3、采样命令、用户设置 schema、源 DEM 或现有
`legacyFocusLod=1` 回滚入口。根因、真实文件指纹和运行时证据见
`docs/product/BUG-2026-07-30-GEOTIFF-OVERVIEW-LOD-TOPOLOGY.md`。

## 2026-07-30：五档质量权利与有界高精度

真实大范围 DEM 证明，设置中的 256/512/1024 没有进入 streaming tile
选择器时只是虚标：三档共享固定 SSE 和 24/56 瓦片预算，1024 甚至无法在
完整视域内达到所需的 64 个同级瓦片。

补充决定：

1. 256/512/1024/2048/4096 表示当前视图可请求的等效长边质量，分别限制
   到 L1/L2/L3/L4/L5；不再表示 file-backed 根概览的尺寸。
2. 256/512/1024 的静止预算分别允许 4/16/64 个同级瓦片，能够完整覆盖
   当前视域；2048/4096 在 192 MiB GPU 硬上限内对屏幕重点区域自适应精化。
3. 禁止把 2048/4096 实现成巨型单网格。低端视域继续显示父层，不能以
   WebGL context loss、主线程冻结或多 GiB 峰值换取名义分辨率。
4. 文件型数据改变质量只触发 tile selection，不重复解码不变根概览。
5. 产品诊断与 Harness 必须报告并断言目标档位、实际最大层级、活动和目标
   顶点/三角形、覆盖完成、队列归零和 GPU 预算；根概览文字不再构成精度
   证据。
6. 2048/4096 只允许 file-backed streaming 路径使用；非流式数据最高
   1024，避免巨型单网格。
7. 活动瓦片必须携带可验证的 horizon visibility；只给隐藏 root 计算遮蔽
   不构成光照完成。
8. 完整进程树内存聚合与 1.5 GiB 上限是发布硬门槛，不得只写入日志。

完整根因与永久回归 Oracle 见
`docs/product/BUG-2026-07-30-GRID-QUALITY-FALSE-ENTITLEMENT.md`。

## 2026-07-30：完整基座与局部精化分离

真实镜头漫游证明，“当前显示集”不能同时作为 GPU 驻留集。否则每次相机
变化都会释放视域外瓦片，完整 TIFF 会退化成不断重复抽样和构网的局部模型。

补充决定：

1. 256/512/1024 分别枚举并永久驻留完整 L1/L2/L3；2048/4096 也必须先
   完成全域 L3，再叠加 L4/L5 局部精化。
2. `requiredBaseTiles` 与 `readyBaseTiles` 不读取当前视锥作为淘汰条件。
   相机只重排尚未开始的基座任务，不取消或重复已开始/已完成的基座。
3. NoData 空瓦片以完成记录参与完整度，防止队列已结束但基座永远不 complete。
4. root overview 顶面只在全部基座 ready 后撤下；此前它只是可见 fallback，
   不能冒充完成的精度。
5. `desiredRefinementTiles` 只表达当前可见精化；
   `residentRefinementTiles` 是 192 MiB 内的 LRU。离开视锥只隐藏，不立即
   dispose；超预算时只淘汰非可见精化。
6. 交互期只能降低 SSAO、Bloom、DOF 等后处理成本，不得改变几何层级。
7. 永久 Harness 冻结构建代次、基座对象 ID、顶点/三角形和分项生命周期
   计数。镜头稳定性通过的充分条件是这些值在真实输入前后完全相同。

该修正取代旧的“显示集合覆盖完成后即可释放父/非选中瓦片”解释。根因记录见
`docs/product/BUG-2026-07-30-TIFF-VIEW-SELECTION-RESIDENCY-COUPLING.md`，
渲染器与生命周期总决策见 ADR-0006。
