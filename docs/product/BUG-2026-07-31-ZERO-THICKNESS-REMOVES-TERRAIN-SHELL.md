# BUG-2026-07-31：零基座厚度错误移除地形实体封闭面

## 状态

已修复并纳入静态与真实输入回归闸门。

## 现象

当“基座厚度”为 0 且流式 LOD 完成全域基座替换后，地形在摄影棚地面上方呈悬空薄片，阴影与地形之间存在明显距离。

## 根因

旧实现把 `baseThickness > 0` 同时解释为“增加厚度”和“是否保留底面”。全域瓦片 ready 后，root 顶面被撤下；当厚度为 0 时，root 的底面与有效区边墙也被一并清空。瓦片只提供地形顶面，因此最终场景失去 Y=0 底面和从 NoData 边界落到底面的封边。

摄影棚地面原先还使用与基座厚度相关的较大负偏移，进一步放大了可见间距。

## 修复语义

- `baseThickness` 仅表示地形表面相对 Y=0 的额外厚度。
- Y=0 底面及有效区边界封边始终保留，流式瓦片只替换 root 顶面。
- 摄影棚地面固定在 Y=-0.002；网格位于 Y=-0.001，仅保留深度冲突安全间距。
- 相机和 LOD 选择不得改变实体封闭状态。

## 回归闸门

- 静态闸门要求 `rootBaseRequired` 和无条件保留 `baseIndices`。
- Release Harness 在 1024 档显式把 `baseThickness` 设为 0，并在流式完成态要求 `rootBasePreserved`；2048/4096 同样不再允许“零厚度隐藏底面”作为通过分支。
- 完成态仍要求 root 顶面关闭、全域覆盖、索引计数精确和请求队列归零。

## 回滚

回滚无条件底面保留、诊断字段和摄影棚地面微偏移即可恢复旧行为；不涉及 TIFF、Core、IPC、设置迁移或最近文件。
